# 知识库归档生命周期修正记录

## 1. 修正目标

知识库归档用于临时下线内容，不等同于删除。归档后保留知识库、文档、Markdown、分块、向量和历史
记录，但停止新增或变更数据，并从普通用户工作区及 RAG 检索范围中移除；恢复后重新开放原有能力。

## 2. 修正内容

- 普通用户和搜索工作台统一通过“可用知识库”接口读取正常状态的知识库。
- 后端权限范围在数据库查询层排除已归档知识库，防止绕过前端直接发起 RAG 或命中率测试。
- 显式提交已归档或无权限知识库时，RAG 返回“所选知识库不可用或无权限”，不静默改查其他知识库。
- 上传、批量删除、回收站恢复和重新处理均在服务层校验知识库状态，归档时返回统一业务错误。
- 管理端继续展示已归档知识库和文档，文档保留查看与详情能力，勾选、上传、重处理、删除和恢复文档
  等写操作改为只读提示。
- 管理端知识库列表保留“恢复”入口；恢复后上传、文档处理、用户侧展示和 RAG 选择自动重新开放。
- 管理端文档响应增加知识库状态，前端不依赖名称或页面缓存推断归档状态。

## 3. 数据影响

- 不删除知识库、文档、原文件、Markdown、分块、向量、任务或历史记录。
- 不新增数据迁移，沿用知识库已有的 `active` 与 `archived` 状态。
- 本次真实页面回归临时归档了“医疗信息化系统”，验证完成后已恢复为正常状态。

## 4. 验证结果

- 后端归档、上传安全、文档生命周期和多知识库检索聚焦测试共 23 项通过。
- Ruff 与 Mypy 通过。
- 前端 TypeScript、ESLint、124 项 Vitest 测试和生产构建通过。
- API、Worker、Web Docker 镜像构建成功，Cython 原生模块校验通过，本地服务全部健康。
- 真实浏览器验证：归档后管理端文档显示“已归档，只读”，不能勾选或重处理；用户知识库列表和 AI
  搜索选项不再显示该知识库；恢复后知识库重新出现在 AI 搜索范围中，并恢复上传入口。

## 5. 剩余环境限制

- 本机全量后端单元测试仍有两个与本次改动无关的 Windows 环境限制：审计测试需要独立测试数据库，
  PDF 导出测试需要 WeasyPrint 原生库。相关归档测试和受影响模块测试均已通过。
