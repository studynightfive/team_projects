# RAG 未命中引用展示修正记录

## 1. 问题现象

检索层找到名称或语义相似的文档片段后，流式接口会立即发送引用；如果大模型随后判断这些片段不足以
回答问题，页面虽然显示“未在文档中找到相关信息”，仍然保留“结论依据”和引用文档，造成结论与证据
状态矛盾。

## 2. 修正内容

- 流式 RAG 改为先生成答案，再决定是否发布引用。
- 大模型明确表示资料不足时，后端响应、会话消息和缓存结果中的引用统一清空。
- 资料不足的回答不写入语义答案缓存，避免无依据答案被其他相似问题复用。
- 系统提示词要求资料不足时使用统一开头，并禁止添加引用编号。
- 前端兼容旧后端或历史数据：识别无文档依据回答后，清空原始结果，隐藏正文引用按钮和“结论依据”。
- 正常命中的答案继续展示去重后的文档依据，不改变现有 RAG 引用交互。

## 3. 验证结果

- 后端流式回答、输入守卫、会话生命周期和答案缓存相关测试共 23 项通过。
- 前端 126 项 Vitest 测试通过。
- Ruff、Mypy、TypeScript、ESLint 和前端生产构建通过。
- 回归测试覆盖正常命中引用延后发布，以及旧接口提前发送引用后最终回答未命中的兼容场景。
