# 云端验收问题修正记录（2026-07-31）

## 修正范围

| 问题 | 根因 | 修正结果 |
|---|---|---|
| 问题改写与缓冲池缺失 | 检索只使用原问题，答案缓存主要依赖标准化文本 | 查询预处理同时生成主查询和近义查询；答案缓存先精确命中，再用 Embedding 余弦相似度与意图特征进行高置信度复用 |
| Langfuse 缺失 | RAG 各阶段没有统一观测适配 | 新增可选单例客户端，覆盖预处理、缓存、检索、重排和生成；配置或网络故障不阻断问答 |
| 删除后列表不刷新 | 删除成功后依赖用户手动刷新 | 前端先按文档 ID 立即移除，再执行一次不切换加载态的静默校准；迟到请求不能覆盖新列表 |
| 下载不能命名 | 导出接口只生成固定名称 | 搜索页和我的下载均可输入基础文件名；后端清理路径字符、控制字符和保留名后追加正确扩展名 |
| 部门看板范围错误 | 部分文档指标按创建者当前部门归属 | 文档、贡献和评测按知识库所属部门聚合；超级管理员切换部门后校验响应范围，其他管理员固定本部门 |
| 重新处理不能改切分方法 | 前端重处理请求未携带切分配置 | 单个与批量重处理均可选择固定长度、语义、递归或格式切分，并设置大小和重叠字符；切分大小统一限制为 200–4000；Worker 重新生成 Markdown、分块和向量 |
| 输入限制只有关键词 | 关键词命中直接拒绝，合法医疗或治理语境容易误伤 | 关键词只作为风险候选，所选聊天模型执行语义意图判断；可识别规避关键词的违规语义，也会放行合法讨论 |

## 关键安全边界

- 相似答案只在同一用户、知识库集合、文档版本、聊天/Embedding/重排模型和检索参数内复用。
- 相似度达到配置阈值后，还必须通过问题类型、否定语义、数字和英文实体兼容检查。
- 文档版本或索引代次变化会形成新的缓存作用域，不会继续返回旧文档答案。
- 语义预检采用防抖；点击查询时复用正在执行的检查，合规后自动提交，违规时停留在输入框并显示统一提示。
- Langfuse 默认不上传问题、文档片段或答案正文；任何观测异常都降级为空操作。
- 重处理完成前继续使用完整旧索引，新一代分块和向量全部成功后原子切换，避免新旧向量混用。

## 云端配置

在 `deploy/env/.env` 中按实际环境配置。不要把真实 Key 提交到仓库：

```dotenv
RAG_ANSWER_CACHE_ENABLED=true
RAG_ANSWER_CACHE_SIMILARITY_THRESHOLD=0.92
RAG_QUERY_REWRITE_ENABLED=true
RAG_SEMANTIC_GUARD_ENABLED=true
RAG_SEMANTIC_GUARD_TIMEOUT_SECONDS=8
RAG_SEMANTIC_GUARD_FAIL_CLOSED=false

LANGFUSE_ENABLED=true
LANGFUSE_PUBLIC_KEY=<public key>
LANGFUSE_SECRET_KEY=<secret key>
LANGFUSE_BASE_URL=https://cloud.langfuse.com
LANGFUSE_ENVIRONMENT=production
LANGFUSE_CAPTURE_CONTENT=false
```

语义缓存依赖可用且维度匹配的 Embedding 模型；语义守卫与改写优先复用用户选择的聊天模型。生产环境若要求“模型不可用也必须拒绝提交”，再把 `RAG_SEMANTIC_GUARD_FAIL_CLOSED` 设为 `true`。

## 验收步骤

1. 在同一知识库依次询问三种近义问题，第二、三次应显示精确或高置信度相似缓存命中，且回答作用域不变。
2. 输入不含显式敏感词但具有涉黄、涉赌或涉毒请求意图的句子，应在输入框提示不合法，且不创建问答轮次；合法医疗、法律和治理问题应放行。
3. 删除文档后当前行应立即消失，页面不闪烁；切换到回收站可看到 30 天恢复期限并可恢复。
4. 勾选多个文档重新处理，选择新的切分方式和参数；观察进度到 100%，随后在文档详情确认配置和新分块。
5. 从搜索页分别导出 Markdown、Word、PDF，自定义文件名；在“我的下载”确认记录名称，并再次选择格式和名称下载。
6. 超级管理员在业务看板切换两个有独立数据的部门，总量、商品问答、评测和贡献榜应随 `scope.department_id` 隔离。
7. 在 Langfuse 中确认一次问答包含 `rag-answer-stream`、`rag-query-preprocess`、`rag-retrieval`、可选 `rag-rerank` 和 `rag-generation`。
