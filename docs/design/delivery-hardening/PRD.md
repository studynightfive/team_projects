# 交付加固 PRD

## 1. 背景

真实环境中的 AI 搜索偶发在流式响应开始后立即失败；桌面端搜索页顶部信息密度和
对齐方式也不稳定。管理端命中率测试虽然已经接入真实检索，但单问题参数与测试集参数
共用，测试集编辑效率不足。项目上云前还需要验证文档回收站、三类角色的数据边界，
并提高知识库和检索核心源码的交付保护强度。

## 2. 目标

1. 医疗信息化知识库的真实流式回答可以持续输出并保存会话、引用和指标。
2. 电脑端搜索页顶部保持单行主标题、知识库范围和紧凑操作区，长名称不会挤压操作。
3. 单问题即时测试拥有独立的 TopK、阈值、模式和重排参数。
4. 管理员可以创建、保存、切换和分别编辑多个测试集；新增问题显示在编辑区顶部。
5. 删除文档立即退出检索，30 天内可以从回收站恢复并重新处理。
6. Linux 生产镜像把知识库服务、知识库权限过滤和智能检索服务编译为 CPython
   `.so`，运行镜像不携带这些模块的 `.py` 源文件。
7. 许可证序列号不通过 Python 接口、日志、异常或序列化结构返回。
8. 普通用户、知识库编辑者和超级管理员使用用户工作区时均符合权限与部门范围。

## 3. 验收标准

- 流式接口在真实 PostgreSQL、Redis、Embedding、Rerank 和聊天模型环境中完成，
  前端收到 `start / stage / citation / delta / done`，不再出现数据库会话失效。
- 1440px、1280px 和 375px 均无页面级横向滚动，顶部操作和底部输入框不遮挡正文。
- 即时测试调整参数不会修改测试集运行参数，后端收到用户当前选择的真实值。
- 新建两个以上测试集后可以独立切换和编辑；保存一个测试集不会覆盖另一个测试集。
- 删除文档显示清理时间，恢复后产生真实重新处理任务；超过 30 天由 Worker 清理。
- Linux API 与 Worker 镜像能够导入 `.so`；被保护模块对应的 `.py` 不存在。
- 开启原生核心或许可证强制开关后，缺失扩展、许可证、签名错误或过期均启动失败，
  错误信息不包含许可证正文、序列号和宿主机路径。
- 三类演示账号分别完成知识库列表、搜索、会话和个人空间的权限回归。

## 4. 约束与风险

- 不修改已有 API URL；OpenAPI 只在请求或响应字段变化时更新。
- SSE 生成器必须使用覆盖整个流生命周期的独立数据库会话。
- Cython 只能增加直接复制和阅读源码的成本，无法阻止拥有容器 root 权限的攻击者
  分析二进制或进程内存。更高等级保护需要远程许可证服务、硬件密钥或机密计算。
- 本地开发和单元测试保留 Python 源码路径；生产镜像通过强制开关拒绝降级。

## 5. 验证范围

- 后端：Ruff、Mypy、Pytest、真实 SSE、文档回收站、原生扩展构建和镜像源文件检查。
- 前端：TypeScript、ESLint、Vitest、生产构建。
- 浏览器：1440px、1280px、375px；普通用户、知识库编辑者、超级管理员。
- 部署：FastAPI 就绪检查、Worker 健康检查、真实模型请求和容器日志脱敏。
